# 智慧尽调 — 流程图

本仓库保存了智慧尽调系统的业务流程图资产。

## 最新变更：报告关联流程调整

原流程由**信贷系统**主动调用尽调系统提供的 2 个 API（未关联尽调申请查询、关联尽调申请）来完成报告与授信业务的关联。

新流程改为在**智慧尽调移动端（H5）**由客户经理直接发起关联。关键变化：

1. 新增 PC 端后端服务：**尽调任务关联服务**。
2. 接口方向反转，由尽调系统调用**信贷系统**提供的 2 个接口：
   - `未关联授信业务查询接口`：入参=客户经理 ID；出参=授信业务数组（授信业务编号、借款人、授信金额、授信时间等）。
   - `关联结果回写接口`：入参=客户经理 ID、授信业务编号、尽调申请编号；出参=关联结果（成功 / 失败）。
3. 移动端第 10 步"报告关联"改为：展示当前客户经理名下可关联的授信业务列表 → 选择 → 提交 → 回写结果。

## 文件

- `flow-diagram.svg` — 可缩放矢量图（推荐用于文档 / 演示）
- `flow-diagram.png` — 位图预览
- `build_diagram.py` — 生成脚本（Python，标准库即可运行）

## 本地重新生成

```bash
python3 build_diagram.py
# 可选：渲染为 PNG（需要 librsvg2-bin）
rsvg-convert -w 1680 -o flow-diagram.png flow-diagram.svg
```
